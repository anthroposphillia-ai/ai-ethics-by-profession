# 직업군별 AI 윤리 실행지침 — 사회복지·보육·요양·교원·상담·약사·교정소방

AI 윤리 원칙은 이미 넘치는데 현장은 바뀌지 않았습니다. 이 책은 원칙을 새로 선언하는 대신, **현장의 결정 지점에 걸리는 실행층 문서**를 7개 직군에 대해 제공합니다.

## 이 책이 답하는 질문

- 우리 기관은 어떤 AI 활용을 금지해야 하는가
- 기록·평가·급여에 AI를 썼을 때 무엇을 남겨야 하는가
- 새 AI 도구를 들일 때 무엇을 확인하고 언제 거절해야 하는가
- 대상자·보호자에게 무엇을 알려주고, 어떤 요구를 들어줘야 하는가
- 위반이 발생했을 때 어떤 조치와 기록이 남는가
