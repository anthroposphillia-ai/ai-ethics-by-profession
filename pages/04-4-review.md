## B. 위험등급 판정

| 등급 | 판정 기준 (하나라도 해당) | 요구 요건 |
|---|---|---|
| **3 등급(고)** | ①대상자 상시 감시·행동 분석(CCTV AI·낙상감지) ②급여·전문서비스 수준 결정 지원 ③대상자에게 직접 제공되는 AI 서비스(돌봄로봇·앱) ④건강·투약 관련 정보 생성·전달 ⑤노인학대·응급 기록 관여 | 운영위원회 심의 + **인간 최종판단 절차 문서화** + 대상자·보호자 고지·동의 + 이의·철회 창구 + 정기 모니터링 + 결과 공개 |
| **2 등급(중)** | 급여제공기록·업무일지·케어플랜 작성 보조 / 비식별 정보 처리 / 내부 문서 초안 | 심의 + 사용 표기 의무(`02`) + 종사자 교육 |
| **1 등급(저)** | 안내문·행사자료 문장 교정, 번역, 홍보 문구(대상자 정보 미입력) | 시설장 확인 + 사용 표기 |

**원칙**
1. 등급이 불명확하면 **상위 등급으로 판정**한다.
2. **등급 숫자가 클수록 위험하다**(1등급이 가장 낮음). 등급명을 함께 적어 혼동을 막는다.
3. 범위 관계: **3등급 ⊃ 규정 제2조 제3호 '고영향 활용' ⊃ AI기본법 제2조 제4호 '고영향 인공지능'**.
4. **대상자 상시 감시가 걸리면 무조건 3등급**이다.
5. **건강·투약 정보 생성 기능이 걸리면 3등급 + 의료행위 금지 검토**를 별도로 받는다.

## C. 계약·도입 요건 체크 (심의 통과 조건)

**C-1. 개인정보·데이터**
- [ ] 입력 데이터의 학습 이용 여부 확인 및 학습 미이용 설정(계약 명시)
- [ ] 데이터 보관 기간·삭제 정책, 국외 이전 여부 확인
- [ ] 처리 위탁·국외이전 시 개인정보 보호법상 고지·동의·안전조치 요건 충족
- [ ] 암호화·접근통제·로그 보존 조항 계약 반영
- [ ] 사고 발생 시 통지 의무·기한 명시

**C-2. 성능·검증**
- [ ] 시험 운영(파일럿) 및 결과 기록 — **오탐·미탐률** 함께 기록(낙상감지 등)
- [ ] 오류·환각 대응 절차 문서화
- [ ] 낙인·차별 표현 생성 사례 점검(해당 등급)
- [ ] 버전 변경·모델 교체 시 재심의 조건 명시
- [ ] 고영향·생성형 AI 서비스 제공 시 **이용자 사전 고지 문구** 준비(AI기본법 제31조 제1항)
- [ ] 영향평가는 법상 **'노력의무'**(제35조) — 기관은 내규로 의무화한 것이므로 이행 기록을 남긴다
- [ ] 완전히 자동화된 결정이 있는 경우 **거부·설명 요구 절차**(개인정보 보호법 제37조의2) 안내 창구 마련

**C-3. 감시 기술 특칙 (A2 = 예인 경우)**
- [ ] 분석 범위에서 **화장실·탈의·목욕 공간 제외** 확인
- [ ] 분석 결과를 **종사자 징계·평가, 대상자 등급 조정**에 쓰지 않음을 계약·내규로 명시
- [ ] 원본 영상 보관 기간 최소화·자동 파기 설정
- [ ] 대상자·보호자 고지문 및 **거부 시 대안(비영상 방식)** 마련
- [ ] 실시간 모니터링 인력·대응 절차(알림 후 조치 흐름) 지정

**C-4. 조직·책임**
- [ ] 담당자·개인정보보호책임자 지정
- [ ] 종사자 교육 계획(도입 전 1회, 의료행위 금지 경계 포함)
- [ ] 표기 방법이 기존 양식에 반영됨
- [ ] 위반·사고 보고 경로 명시

**C-5. 대상자 권리 (3등급 및 직접 제공 서비스)**
- [ ] 고지문·동의 절차 준비(`04`) — **본인 의사 확인 → 후견인 동의 순서**
- [ ] 열람·정정·이의제기 접수 창구 및 법정 기한(10일)
- [ ] 사람에 의한 돌봄으로 전환 가능한 절차
- [ ] 감시 기술 **철회 요구 처리 절차**

## D. 운영 중 점검 (분기 1회)

- [ ] 표기 누락 0건인가 (`02`)
- [ ] 위반·사고·요구 접수 및 조치 기록(없어도 "0건"으로 기록)
- [ ] 등록 도구 목록과 실제 사용 도구 일치(**미등록 도구 사용 여부**)
- [ ] 서비스 약관·모델 버전 변경 여부(있으면 재심의)
- [ ] 교육 이수율
- [ ] CCTV AI 오탐·미탐 사례와 대응 기록
- [ ] 급여기록 정확성 점검 결과(심사 대응 건수)

## F. 불승인 기준

1. 대상자 정보를 학습에 이용하며 해제가 불가능한 서비스
2. 건강·투약을 자동 생성·지시하는 서비스(의료행위 침범)
3. 분석 결과를 종사자 징계·평가에 쓰는 것을 계약상 허용하는 감시 시스템
4. 오류·이의제기 창구가 없고 제공자가 대응 의무를 지지 않는 서비스
5. 3등급인데 인간 최종판단 절차를 문서화할 수 없는 경우
6. 사고 통지·삭제 요구에 대한 계약상 근거가 없는 경우
