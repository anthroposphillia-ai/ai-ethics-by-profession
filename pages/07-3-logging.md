> 목적: AI 활용을 **기록 단계에서 흔적으로 남긴다.** 복약지도·조제·검수·검사 기록은 환자 안전과 법적 책임의 근거이므로, 표기는 ①책임 소재 ②검증 여부 ③사후 확인 가능성을 확보하는 장치다.
> 근거: 「○○○(약국·의료기관) AI 활용 규정」 제12조 — 실행 트리거 ① / 기준일 2026-10-12 / v0.1

## 1. 표기 대상 문서

| 문서 유형 | 표기 | 비고 |
|---|---|---|
| 복약지도 기록 | **필수** | 검증한 정보원 표시 |
| 조제·검수 기록 | **필수** | AI 검수 사용 시 그 범위 명시 |
| 검사 업무일지·검체 관리 기록 | **필수** | |
| 검사결과 요약·전달 자료 | **필수** | 해석·전달은 담당 의사 경유 |
| 환자 안내문·복약 안내 자료 | **필수** | 검증 여부 포함 |
| 업무 보고서·통계 | **필수** | |
| 개인 메모·연습 초안(외부 미제출) | 불요 | 단 환자 정보 입력 금지(규정 제5조) 유지 |
| **이상 소견 보고·환자 피해 관련 기록** | **표기 불가·AI 사용 금지** | 원문 그대로 기록 |

## 2. 표기 형식 (문서 말미 고정란)

```
[AI 활용 표기]
· 활용 여부: □ 사용  □ 미사용
· 도구: (예: 기관 계약 생성형AI A / 조제검수 B) / 버전·접속일
· 활용 범위: 문장 다듬기 / 의약품 정보 조회 / 요약 / 번역 / 검수 보조
· 입력 정보: 비식별 가공 후 입력 (환자 개인정보 미입력)
· 검증: 식약처 공인 정보원·기관 DB 교차 확인 완료 / 미해당
· 최종 확인·판단: 담당 ○○○ (면허·직종)
```

**양식 개정 권고(우선 조치)**: 복약지도·조제검수·검사 업무일지 양식 말미에 위 체크란을 **기본 삽입**한다.

## 3. 기록 시 지켜야 할 3원칙

1. **의약품·검사 정보는 공인 자료로 확인한 값만 기록한다** — AI가 제시한 용량·상호작용은 공인 정보원 확인 후에만 기록·안내한다(규정 제9조).
2. **원문과 산출물을 분리 보관** — AI에 입력한 텍스트와 최종 기록을 따로 남긴다(열람·정정 요구·사고 조사 대응).
3. **삭제하지 않는다** — 오류를 발견해 수정한 경우 경위를 남긴다. 조제·검수 오류는 재발 방지 자료가 된다.

## 4. 오류·이상 사례 기록 (핵심)

AI 관련 오류·이상 사례는 **반드시 기록하고 보고**한다.

- AI가 제시한 정보와 공인 정보의 **불일치 사례**
- AI 검수가 놓친 오류(과·오조제 위험, 상호작용 누락)
- AI 요약으로 환자 안내가 잘못된 사례
- 조치: 즉시 사용 중단 → 보고 → 재발 방지(도구 설정·교육·계약 조건 변경)

## 5. 점검·위반 연결

- 분기 자체점검(`03`) 지표: 표기 누락 0건 / **미검증 AI 정보 사용 0건**
- 표기 누락 1회 → 보완 지도 / 반복 또는 환자 안전 관련 → 규정 제19조에 따른 조치
- 연 1회, 오류·이상 사례를 익명화해 종사자 교육 자료로 공유한다.

## 6. 현장용 4줄 요약 (교육 자료용)

1. AI 썼으면 **기록 끝에 밝힌다.**
2. **환자 이름·처방전·검사결과는 절대 붙여넣지 않는다.**
3. **용량·상호작용은 AI 말고 공인 정보원으로 확인한다.**
4. **판독·진단·복약지도는 AI가 하지 않는다.** (권한 있는 사람이 한다)
