> 목적: AI 활용을 **기록 단계에서 흔적으로 남긴다.** 상담기록은 민감정보이므로 표기는 ①책임 소재 ②검증 여부 ③사후 확인 가능성을 확보하는 장치다.

## 2. 표기 형식 (문서 말미 고정란)

```
[AI 활용 표기]
· 활용 여부: □ 사용  □ 미사용
· 도구: (예: 기관 계약 생성형AI A) / 버전·접속일
· 활용 범위: 문장 다듬기 / 요약 / 번역 / 검사 채점 보조
· 입력 정보: 비식별 가공 후 입력 (내담자 개인정보 미입력)
· 검증: 사실·진단기준·인용 확인 / 담당자 해석 여부
· 최종 작성·판단: 담당 ○○○
```

**양식 개정 권고(우선 조치)**: 상담기록·사례개념화·슈퍼비전 양식 말미에 위 체크란을 **기본 삽입**한다.

## 3. 기록 시 지켜야 할 3원칙

1. **위기 관련 진술은 원문으로** — 내담자의 표현(직접 인용)을 보존한다. AI 요약·윤문은 위험 신호를 약화시킨다.
2. **원문과 산출물을 분리 보관** — AI에 입력한 텍스트와 최종 문서를 따로 남긴다(열람·정정 요구 대응).
3. **삭제하지 않는다** — 오류를 발견해 수정한 경우 경위를 남긴다.

## 4. 슈퍼비전·사례회의에서 확인할 사항

- 이 기록에서 AI가 만든 문장은 어느 부분인가? 원문과 일치하는가?
- **위험 신호(자살·자해·학대)가 약화·누락된 부분이 있는가?**
- AI가 만든 공감·반영 문구가 내담자에게 전달되었는가?
- 낙인·진단적 단정 표현("치료불가", "경계선")이 들어오지 않았는가?
- 검사 해석을 자격자 없이 AI 결과로 대체한 부분이 있는가?

## 5. 점검·위반 연결

- 분기 자체점검(`03`) 지표: 표기 누락 0건 / **위기 기록의 AI 사용 0건**
- 표기 누락 1회 → 보완 지도 / 반복 또는 위기·고영향 문서 → 규정 제20조에 따른 조치
- 연 1회, 우수·위험 사례를 익명화해 종사자 교육 자료로 공유한다.

## 6. 현장용 4줄 요약 (교육 자료용)

1. AI 썼으면 **기록 끝에 밝힌다.**
2. **이름·축어록·검사 원자료는 절대 붙여넣지 않는다.**
3. **위기 이야기는 AI에게 요약시키지 않는다.** (원문 그대로, 내담자 말 그대로)
4. **진단·해석은 AI가 하지 않는다.** (자격자가 판단한다)
