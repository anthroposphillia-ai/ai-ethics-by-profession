## B. 위험등급 판정

| 등급 | 판정 기준 (하나라도 해당) | 요구 요건 |
|---|---|---|
| **3 등급(고)** | ①약물 요법·조제·검수 관여 ②판독·진단 관여 ③환자 직접 제공 서비스 ④건강정보(민감정보) 처리 ⑤의약품 정보 생성·전시 | 심의 + **인간 최종판단 절차 문서화** + 공인 정보원 검증 절차 + 환자 고지·동의 + 이의 창구 + 정기 모니터링 |
| **2 등급(중)** | 업무일지·안내문·보고서 작성 보조, 비식별 정보 처리, 재고·일정 관리 | 심의 + 사용 표기 의무(`02`) + 종사자 교육 |
| **1 등급(저)** | 안내문 문장 교정, 번역(환자 정보 미입력) | 기관장(대표자) 확인 + 사용 표기 |

**원칙**
1. 등급이 불명확하면 **상위 등급으로 판정**한다.
2. **등급 숫자가 클수록 위험하다**(1등급이 가장 낮음).
3. 범위 관계: **3등급 ⊃ 규정 제2조 제3호 '고영향 활용' ⊃ AI기본법 제2조 제4호 '고영향 인공지능'**.
4. **약물 요법·조제·판독에 관여하면 무조건 3등급**이다.
5. 법령상 **권한 없는 진단·판독을 산출하는 구성은 즉시 불승인**한다.

## C. 계약·도입 요건 체크 (심의 통과 조건)

**C-1. 개인정보·데이터**
- [ ] 입력 데이터의 학습 이용 여부 확인 및 학습 미이용 설정(계약 명시)
- [ ] 데이터 보관 기간·삭제 정책, 국외 이전 여부 확인
- [ ] 처리 위탁·국외이전 시 개인정보 보호법상 고지·동의·안전조치 요건 충족
- [ ] 암호화·접근통제·로그 보존 조항 계약 반영
- [ ] 사고 발생 시 통지 의무·기한 명시

**C-2. 성능·안전 (핵심)**
- [ ] 파일럿 운영 및 결과 기록 — **오탐·미탐률, 위험 미탐지 사례** 필수
- [ ] **의약품 정보 검증 절차**(공인 정보원 교차확인) 문서화
- [ ] 결과에 **출처·근거 표시** 기능이 있는지(불투명하면 불승인 검토)
- [ ] 오류·환각 신고 창구와 처리 절차
- [ ] 버전 변경·모델 교체 시 재심의 조건 명시
- [ ] 고영향·생성형 AI 서비스 제공 시 **이용자 사전 고지 문구** 준비(AI기본법 제31조 제1항)
- [ ] 영향평가는 법상 **'노력의무'**(제35조) — 기관은 내규로 의무화한 것이므로 이행 기록을 남긴다
- [ ] 완전히 자동화된 결정이 있는 경우 **거부·설명 요구 절차**(개인정보 보호법 제37조의2) 안내 창구 마련

**C-3. 업무 범위 준수 (불승인 판단 기준과 직결)**
- [ ] 판독·진단·처방 결정을 **자동 확정**하지 않는다(의사 권한 침범 금지)
- [ ] 조제·검수 AI는 **약사 최종 검수**를 전제로 설계됨
- [ ] 검사결과가 환자에게 **담당 의사 경유**로 전달되는 기관 절차와 충돌하지 않음

**C-4. 조직·책임·권리**
- [ ] 담당자·개인정보보호책임자 지정
- [ ] 종사자 교육 계획(도입 전 1회, 업무 범위·검증 절차 포함)
- [ ] 환자 고지문·동의 절차 준비(`04`)
- [ ] 열람·정정·이의제기 창구 및 법정 기한(10일)
- [ ] 사람에 의한 응대로 전환 가능한 절차(**대면 복약지도 유지**)

## D. 운영 중 점검 (분기 1회)

- [ ] 표기 누락 0건 / **미검증 AI 정보 사용 0건** (`02`)
- [ ] 오류·이상 사례 신고 및 조치 기록(없어도 "0건"으로 기록)
- [ ] 등록 도구 목록과 실제 사용 도구 일치(**미등록 도구·개인 계정 사용 여부**)
- [ ] 서비스 약관·모델 버전 변경 여부(있으면 재심의)
- [ ] 교육 이수율
- [ ] 조제·검수 오류 건수와 원인 분석(재발 방지 조치)

## F. 불승인 기준

1. 환자 정보를 학습에 이용하며 해제가 불가능한 서비스
2. **판독·진단을 자동 확정**해 환자에게 전달하는 구성(의사 권한 침범)
3. 의약품 정보에 **출처·근거를 제시하지 않는** 서비스
4. 조제·검수 AI를 **약사 최종 검수 없이** 운영하도록 설계된 구성
5. 오류·이의제기 창구가 없고 제공자가 대응 의무를 지지 않는 서비스
6. 3등급인데 인간 최종판단 절차·검증 절차를 문서화할 수 없는 경우
