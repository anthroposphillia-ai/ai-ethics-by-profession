## B. 위험등급 판정

| 등급 | 판정 기준 (하나라도 해당) | 요구 요건 |
|---|---|---|
| **3 등급(고)** | ①내담자 직접 제공(챗봇·앱) ②위기 신호 처리 경로 포함 ③축어록·녹음·영상·검사 원자료 처리 ④위험평가·선별·진단 지원 ⑤정신건강 민감정보 처리 | 윤리위원회 심의 + **인간 최종판단 절차 문서화** + **위기 대응 프로토콜** + 내담자 고지·동의 + 이의 창구 + 정기 모니터링 |
| **2 등급(중)** | 상담기록·사례개념화 작성 보조, 비식별 요약, 내부 보고서 초안 | 심의 + 사용 표기 의무(`02`) + 종사자 교육 |
| **1 등급(저)** | 안내문·홍보물 문장 교정, 번역, 일정 관리(내담자 정보 미입력) | 기관장 확인 + 사용 표기 |

**원칙**
1. 등급이 불명확하면 **상위 등급으로 판정**한다.
2. **등급 숫자가 클수록 위험하다**(1등급이 가장 낮음).
3. 범위 관계: **3등급 ⊃ 규정 제2조 제3호 '고영향 활용' ⊃ AI기본법 제2조 제4호 '고영향 인공지능'**.
4. **위기 신호가 경로에 걸리면 무조건 3등급 + 프로토콜 필수**다.
5. **내담자에게 직접 제공되는 챗봇은 3등급**이다. 사람 연계 창구가 없으면 불승인.

## C. 계약·도입 요건 체크 (심의 통과 조건)

**C-1. 개인정보·데이터**
- [ ] 입력 데이터의 학습 이용 여부 확인 및 학습 미이용 설정(계약 명시)
- [ ] 데이터 보관 기간·삭제 정책, 국외 이전 여부 확인
- [ ] 처리 위탁·국외이전 시 개인정보 보호법상 고지·동의·안전조치 요건 충족
- [ ] 민감정보(정신건강) 처리 근거 확인 — 별도 동의 또는 법령 근거
- [ ] 암호화·접근통제·로그 보존 조항 계약 반영
- [ ] 사고 발생 시 통지 의무·기한 명시

**C-2. 성능·검증**
- [ ] 파일럿 운영 및 결과 기록 — **위기 신호 포착률·미탐 사례** 필수 점검
- [ ] 위기 대응 프로토콜 시험(모의 시나리오) 실시
- [ ] 오류·환각 대응 절차 문서화
- [ ] 편향·낙인 표현 사례 점검
- [ ] 버전 변경·모델 교체 시 재심의 조건 명시
- [ ] 생성형 AI 서비스 제공 시 **이용자 사전 고지 문구** 준비(AI기본법 제31조 제1항)
- [ ] 영향평가는 법상 **'노력의무'**(제35조) — 기관은 내규로 의무화한 것이므로 이행 기록을 남긴다
- [ ] 완전히 자동화된 결정이 있는 경우 **거부·설명 요구 절차**(개인정보 보호법 제37조의2) 안내 창구 마련

**C-3. 위기 대응 (A3·A10 = 예인 경우 필수)**
- [ ] 위기 신호 정의·감지 기준 문서화
- [ ] 감지 후 **사람 상담자 연계 시간 기준**(예: 즉시, 최대 ○분) 명시
- [ ] 연계 실패 시 대안 경로(전화·문자·긴급번호 안내)
- [ ] 위기 관련 대화의 **AI 요약 금지** 설정
- [ ] 연계·조치 이력 자동 기록 및 정기 검토
- [ ] 챗봇 한계 고지문("이 서비스는 사람 상담을 대신하지 않습니다")

**C-4. 조직·책임·권리**
- [ ] 담당자·개인정보보호책임자 지정
- [ ] 종사자 교육 계획(도입 전 1회, 위기 대응 포함)
- [ ] 내담자 고지문·동의 절차 준비(`04`) + 14세 미만 법정대리인 동의
- [ ] 열람·정정·이의제기 창구 및 법정 기한(10일)
- [ ] 사람에 의한 상담으로 전환 가능한 절차

## D. 운영 중 점검 (분기 1회)

- [ ] 표기 누락 0건 / **위기 기록의 AI 사용 0건** (`02`)
- [ ] 위기 연계 발생 건수·처리 시간·결과 기록
- [ ] 위반·사고·내담자 요구 접수 및 조치 기록(없어도 "0건"으로 기록)
- [ ] 등록 도구 목록과 실제 사용 도구 일치(**미등록 도구·개인 계정 사용 여부**)
- [ ] 서비스 약관·모델 버전 변경 여부(있으면 재심의)
- [ ] 교육 이수율, 위기 프로토콜 모의훈련 실시 여부

## F. 불승인 기준

1. 내담자 정보를 학습에 이용하며 해제가 불가능한 서비스
2. **위기 신호 감지 후 사람 연계 경로가 없는 챗봇·자동응답**
3. 진단·심리검사 해석을 자동 확정해 내담자에게 전달하는 구성
4. 축어록·녹음 파일을 그대로 학습·보관하는 서비스(삭제·비식별 근거 없음)
5. 오류·이의제기 창구가 없고 제공자가 대응 의무를 지지 않는 서비스
6. 3등급인데 인간 최종판단 절차·위기 프로토콜을 문서화할 수 없는 경우
