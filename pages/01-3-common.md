## 7개 세트가 공유하는 골격

직군이 달라도 실행층이 갖춰야 할 뼈대는 동일합니다. 이 골격만 유지하면 다른 직군에도 이식할 수 있습니다.

### 1. 조문 구조(내규 21~23조)

| 장 | 내용 |
|---|---|
| 제1장 총칙 | 목적 / 정의(고영향 활용 — 법 정의 흡수) / 기본원칙 / 적용범위 |
| 제2장 정보 보호 | 입력 금지 정보 / 가명·최소화 / 위탁·국외이전 / 학습이용 금지 확인 + **직군 특칙** |
| 제3장 활용 기준 | 사용 표기 / 인간 최종판단 / 비차별 / 정확성 검증 / 대상별 제한 |
| 제4장 절차 | 담당자 지정 / 도입 심의 / 대상자 권리 / 위반 조치 / 교육 / 자체점검 |
| 제5장 보칙 | 개정 |

### 2. 직군 특칙이 품질을 결정한다

일반 기관 규정을 복사하면 반드시 빠지는 것이 **직군 고유 위험**입니다. 각 세트는 최소 3개를 조문화했습니다.

| 직군 | 직군 특칙(요지) |
|---|---|
| 사회복지 | 사례관리 판단은 참고만, 클라이언트 대면 상담 대체 금지 |
| 보육 | 영유아 초상 생성·합성 금지, 발달 선별 금지, 아동학대 의심기록 AI 금지 |
| 요양 | 동의능력·후견 순서, 의료행위 금지 경계, 감시 최소화, 급여기록 정확성 |
| 교원 | 생활기록부 직접 기재 금지, AI 탐지기 단독 처분 금지, 재채점·재심 |
| 상담 | 위기 상황 사람 연계, 진단·검사 해석 자격 제한, 챗봇 한계 고지 |
| 약사·의료기사 | 의약품 정보 공인 정보원 검증, 판독·진단 권한, 조제·검수 최종 책임 |
| 교정·소방 | 위험 예측 단독 처분 금지, 생체정보 법적 근거, 응급 시 AI 우회 |

### 3. 위험등급 3단계(공통)

| 등급 | 의미 | 예 |
|---|---|---|
| 3등급(고) | 권리·안전에 직접 영향 | 초상 생성, 발달 선별, 위험 예측, 생체정보, 급여·평가 결정 |
| 2등급(중) | 문서·기록 작성 보조 | 기록 윤문, 요약, 초안 생성 |
| 1등급(저) | 영향 없음 | 안내문 교정, 번역 |

**등급 숫자가 클수록 위험합니다**(1등급이 가장 낮음). 범위 관계는 `3등급 ⊃ 기관 정의 '고영향 활용' ⊃ 법상 '고영향 인공지능'`입니다.

### 4. 기한(공통)

| 요구 | 기한 | 근거 |
|---|---|---|
| 개인정보 열람 | 10일 이내 | 개인정보 보호법 제35조·시행령 제41조 |
| 정정·삭제 | 10일 이내 | 제36조·시행령 제43조 |
| 기관 자체 이의제기 | 10영업일 | 기관 절차 |
| 자동화된 결정 거부·설명 요구 | 법정 절차 | 제37조의2·시행령 제44조의2 |

법정 기한(10일, 역일)과 기관 자체 기한(10영업일)을 **섞어 적용하지 않습니다.**
