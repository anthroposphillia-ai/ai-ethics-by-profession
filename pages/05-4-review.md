```

## B. 위험등급 판정

| 등급 | 판정 기준 (하나라도 해당) | 요구 요건 |
|---|---|---|
| **3 등급(고)** | ①성적·평가·진급 판단 지원 ②부정행위·표절 판정 ③학생 상담·건강 정보 처리 ④학생 이미지·음성 생성·분석 ⑤학생 직접 제공 서비스(챗봇·튜터) | 교무회의·운영위 심의 + **인간 최종판단 절차 문서화** + 학생·학부모 고지·동의 + **이의제기·재심 창구** + 정기 모니터링 + 결과 공개 |
| **2 등급(중)** | 학습자료·문항 초안 생성, 문장 교정, 번역, 비식별 정보 처리 | 심의 + 사용 표기 의무(`02`) + 교원 연수 |
| **1 등급(저)** | 안내문·행사자료 문장 교정, 홍보 문구(학생 정보 미입력) | 학교장 확인 + 사용 표기 |

**원칙**
1. 등급이 불명확하면 **상위 등급으로 판정**한다.
2. **등급 숫자가 클수록 위험하다**(1등급이 가장 낮음) — 등급명을 함께 적는다.
3. 범위 관계: **3등급 ⊃ 규정 제2조 제3호 '고영향 활용' ⊃ AI기본법 제2조 제4호 '고영향 인공지능'**.
4. **AI 탐지기가 걸리면 무조건 3등급**이다. 오탐이 곧 학생 불이익이다.
5. **채점 자동화가 걸리면 3등급 + 배점 근거 기록 의무**를 별도로 부과한다.

## C. 계약·도입 요건 체크 (심의 통과 조건)

**C-1. 개인정보·데이터**
- [ ] 입력 데이터의 학습 이용 여부 확인 및 학습 미이용 설정(계약 명시)
- [ ] 데이터 보관 기간·삭제 정책, 국외 이전 여부 확인
- [ ] 처리 위탁·국외이전 시 개인정보 보호법상 고지·동의·안전조치 요건 충족
- [ ] 14세 미만 학생 정보 처리 시 **법정대리인 동의 절차** 마련
- [ ] 암호화·접근통제·로그 보존 조항 계약 반영
- [ ] 사고 발생 시 통지 의무·기한 명시

**C-2. 성능·검증 (특히 탐지기·채점)**
- [ ] 시험 운영(파일럿) 및 결과 기록 — **오탐·미탐률** 필수 기록
- [ ] **탐지 결과를 단독 처분 근거로 삼지 않는다**는 사용 규칙이 매뉴얼·계약에 명시
- [ ] 채점 도구는 **배점 근거·채점 기준 로그** 제공 여부 확인
- [ ] 오류·환각 대응 절차 문서화
- [ ] 편향·차별 가능성 점검(언어·배경이 다른 학생)
- [ ] 버전 변경·모델 교체 시 재심의 조건 명시
- [ ] 고영향·생성형 AI 서비스 제공 시 **이용자 사전 고지 문구** 준비(AI기본법 제31조 제1항)
- [ ] 영향평가는 법상 **'노력의무'**(제35조) — 학교는 규정으로 의무화한 것이므로 이행 기록을 남긴다
- [ ] 완전히 자동화된 결정이 있는 경우 **거부·설명 요구 절차**(개인정보 보호법 제37조의2) 안내 창구 마련

**C-3. 학생 권리 (3등급 및 직접 제공 서비스)**
- [ ] 안내문·동의 절차 준비(`04`) — **학생 본인 의사 + 법정대리인 동의**
- [ ] **재채점·재심 요구** 접수 창구와 처리 기한
- [ ] 사람에 의한 채점·평가로 전환 가능한 절차
- [ ] 학생이 AI 사용을 거부해도 **평가상 불이익이 없다**는 원칙 명시

**C-4. 조직·책임**
- [ ] 담당자·개인정보보호 담당자 지정
- [ ] 교원 연수 계획(도입 전 1회)
- [ ] 표기 방법이 기존 양식에 반영됨
- [ ] 위반·사고 보고 경로 명시
- [ ] 학업성적관리규정·학교생활기록 지침과의 정합성 검토

## D. 운영 중 점검 (학기 1회)

- [ ] 표기 누락 0건인가 (`02`)
- [ ] 위반·사고·이의제기 접수 및 조치 기록(없어도 "0건"으로 기록)
- [ ] 등록 도구 목록과 실제 사용 도구 일치(**미등록 도구 사용 여부** — 교원 개인 계정 사용 포함)
- [ ] 서비스 약관·모델 버전 변경 여부(있으면 재심의)
- [ ] 연수 이수율
- [ ] **탐지기 오탐 사례와 학생 소명 처리 기록**
- [ ] 재채점·재심 처리 건수와 결과

## E. 심의 기록 양식 (최소 항목)

```

· 조건부 승인 시 이행 조건·기한·확인자

## F. 불승인 기준

1. 학생 정보를 학습에 이용하며 해제가 불가능한 서비스
2. **탐지 결과를 단독 처분 근거로 삼도록 설계**된 도구
3. 채점 근거·배점 로그를 제공하지 않는 자동 채점 도구
4. 오류·이의제기 창구가 없고 제공자가 대응 의무를 지지 않는 서비스
5. 3등급인데 인간 최종판단 절차를 문서화할 수 없는 경우
6. 14세 미만 학생 정보의 법정대리인 동의 절차를 마련할 수 없는 경우
