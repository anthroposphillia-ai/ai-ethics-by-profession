> 목적: AI 활용을 **환자가 알 수 있고, 멈출 수 있고, 되돌릴 수 있게** 만든다. 단 **응급·이상 소견 상황에서는 고지·동의가 조치를 지연시켜서는 안 된다.**
> 근거: 「○○○(약국·의료기관) AI 활용 규정」 제17조 — 실행 트리거 ③, 「개인정보 보호법」(제23조·제35조~제37조의2), 의료법·약사법상 설명·복약지도 의무 / 기준일 2026-10-12 / v0.1

## 1. 적용 대상

| 상황 | 고지 | 동의 | 열람·정정·이의 |
|---|---|---|---|
| 복약지도에 AI 사용 (3등급) | 필수 | 고지로 갈음, 거부 시 약사 직접 안내 | 필수 |
| AI 조제·검수 도구 사용 (3등급) | 필수(접수·조제 시) | 고지로 갈음 | 필수 |
| 판독 보조 도구 사용 (3등급) | 필수(검사 안내문) | **필수**(검사 동의 절차에 포함) | 필수 |
| 환자 직접 제공 서비스(복약 챗봇·앱) (3등급) | 필수 | **필수** | 필수 + 약사 연계 창구 |
| 업무일지·안내문 작성 보조 (2등급) | 불요(내부) | 불요 | 해당 없음 |
| 안내문 문장 교정 (1등급) | 불요 | 불요 | 해당 없음 |

## 2. 고지 사항 (7개 항목)

1. 어떤 업무에 AI를 쓰는가 (예: "복약 안내문 정리, 검사 영상 판독 보조")
2. **무엇을 하지 않는가** (예: "판독·진단·처방 결정은 의사가 합니다. 복약지도는 약사가 합니다")
3. 어떤 정보가 입력되고, 무엇은 입력하지 않는가
4. AI 활용을 거부할 수 있고 **거부해도 진료·조제·복약지도에 불이익이 없다**는 사실
5. 거부 시 대안(사람에 의한 안내)의 내용
6. 열람·정정·이의제기 창구와 법정 기한(10일)
7. 챗봇 사용 시: 사람 상담(약사·의사)을 대신하지 않는다는 한계와 연계 방법

## 3. 창구·복약지도 시 스크립트 (그대로 읽어도 되게)

> "○○님, 저희는 복약 안내문을 정리하거나 검사 결과를 정리할 때 컴퓨터 프로그램(AI)의 도움을 받는 경우가 있습니다. 약 이름·용량·상호작용은 공식 자료로 다시 확인합니다. 진단과 판독은 의사가, 복약지도는 약사가 직접 합니다. 원하지 않으시면 쓰지 않습니다 — 진료나 조제에 아무 불이익이 없습니다. AI가 잘못 안내한 부분이 있으면 알려주시면 바로 고치고, 그 내용은 기록으로 남깁니다. 담당은 저(○○○)입니다."

## 4. 동의 기록 양식 (3등급 및 직접 제공 서비스)

```
· 환자: ○○○  · 생년월일: ○○○○-○○-○○
· 동의 주체: □ 환자 본인  □ 법정대리인(관계: ) ※ 의사결정능력 저하 시 절차 별도
· 설명 내용(체크): □ 활용 범위  □ 미활용 범위  □ 입력 금지 정보  □ 거부권·불이익 없음  □ 대안  □ 창구
· 동의 범위(각각 별도 동의): □ 복약 안내 보조  □ 조제·검수 도구 사용  □ 판독 보조  □ 챗봇 사용
· 동의 여부: 동의 / 거부 / 부분 동의(범위: )
· 설명자: ○○○ (면허·직종) / 서명 또는 날짜
· 재확인 시점: (예: 입원·장기 복약 변경 시, 서비스 변경 시)
```
※ **판독 보조 동의와 복약 안내 보조 동의를 묶지 않는다.**

## 5. 열람·정정·이의제기·철회 절차

**접수** — 창구: 담당 약사·기사 / 기관 대표번호 / 서면·구두(구두는 접수자가 기록)

**처리 흐름**
```
접수(당일 기록) → 접수 확인 회신 → 1차 확인(기록 원문·AI 활용 내역 대조)
  → ① 열람 요구: 10일 이내 열람 조치 (개인정보 보호법 제35조·시행령 제41조)
  → ② 정정·삭제 요구: 10일 이내 조치 및 결과 통지 (제36조·시행령 제43조) — 정정 이력 남김
  → ③ 이의제기(AI 안내·검수로 피해 주장): 담당자 아닌 제3자(관리담당자 또는 윤리위원회)가 검토
      → 접수일부터 10영업일 내 결정·통지, 필요 시 재심
  → ④ 완전히 자동화된 결정에 대한 거부·설명 요구: 법정 절차로 즉시 안내·처리
      (개인정보 보호법 제37조의2, 시행령 제44조의2)
  → ⑤ 챗봇 사용 중단 요청: 즉시 중단 + 사람(약사·의사) 응대 전환

※ ①·②는 법정 기한(10일, 역일), ③은 기관 자체 절차(10영업일)다. 섞어 적용하지 않는다.
```

**기록 필수 항목**: 접수일·요구 내용·검토자·결정·통지일·조치. **기각이어도 기록한다.** 분기별 접수·처리 건수를 집계해 공개한다.

> **'인적 개입'의 기준(중요)**: 개인정보위 고시는 인적 개입을 **결정을 바꿀 권한이 있는 사람이 실질적으로 관여하는 것**으로 본다. 형식적 확인만으로는 인정되지 않는다 — 검토자가 산출물을 확인하고 근거를 기록하며 필요 시 **판단을 뒤집을 수 있어야** 한다.

## 6. 예외 (응급·이상 소견)

1. **응급 상황·이상 소견에서는 고지·동의 절차가 조치를 지연시켜서는 안 된다.** 필요한 응급 조치·의사 보고는 AI 사용 여부와 무관하게 즉시 이행한다.
2. AI가 제시한 정보로 인한 **환자 피해 가능성이 확인되면** 즉시 사용을 중단하고 환자 통지·경과 확인을 한다(규정 제19조 제3호).
3. 이상 소견 보고 기록은 AI 요약을 사용하지 않는다.

## 7. 불이익 금지 조항

- AI 활용 거부, 열람·정정·이의 요구를 이유로 **진료·조제·복약지도를 제한하거나 차별**해서는 아니 된다.
- 위 사항을 종사자 교육에 포함하고, 위반 시 규정 제19조에 따른다.

## 8. 환자 안내문 1쪽 골격

```
① 우리 기관이 AI를 쓰는 곳 / 쓰지 않는 곳
② 입력하지 않는 정보 (이름·처방전·검사결과 원본)
③ 판독·진단·복약지도는 사람이 한다는 설명
④ 의약품 정보는 공인 자료로 확인한다는 설명
⑤ 거부해도 불이익이 없다는 설명
⑥ 문의·열람·정정 창구와 법정 기한(10일), 시행일
⑦ 담당자 이름·연락처
```
