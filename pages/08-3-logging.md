> 목적: AI 활용을 **기록 단계에서 흔적으로 남긴다.** 처우·징계·출동·구조 기록은 신분·권리에 영향을 주고 사후 검증 대상이 되므로, 표기는 ①책임 소재 ②검증 여부 ③증거력 보존을 확보하는 장치다.
> 근거: 「○○○(교정·소방)기관 AI 활용 규정」 제13조 — 실행 트리거 ① / 기준일 2026-10-12 / v0.1

## 1. 표기 대상 문서

| 문서 유형 | 표기 | 비고 |
|---|---|---|
| 처우·분류·수용 장소 결정 기록 | **필수** | 위험 예측 AI 사용 시 점수·근거 병기 |
| 징계·조사 기록 | **필수** | AI 요약 사용은 원문 별첨 필수 |
| 사고·자해·응급 대응 기록 | **표기 + 원문 필수** | 요약으로 대체 금지 |
| 출동·구조·구급 활동 기록 | **필수** | AI 지원 사용 범위 명시 |
| 대민 안내문·재난 정보 | **필수** | 출처 확인 여부 포함 |
| 내부 업무 보고서·통계 | **필수** | |
| 개인 메모·연습 초안(미제출) | 불요 | 단 직무 정보 입력 금지(규정 제5조) 유지 |

## 2. 표기 형식 (문서 말미 고정란)

```
[AI 활용 표기]
· 활용 여부: □ 사용  □ 미사용
· 도구: (예: CCTV행동분석 A / 위험예측 B / 생성형AI C) / 버전·접속일
· 활용 범위: 요약 / 문장 다듬기 / 위험 예측 참고 / 영상 분석 / 출동 지원
· 입력 정보: 비식별 가공 후 입력 (개인식별·생체정보 미입력)
· 검증: 사실·법령·출처 확인 완료 / 담당자 종합 판단 여부
· 최종 판단: 담당 ○○○ (직위) / 지휘관 ○○○
```

**양식 개정 권고(우선 조치)**: 처우·징계·사고·출동 기록 양식 말미에 위 체크란을 **기본 삽입**한다.

## 3. 위험 예측 결과 기록(필수 항목)

위험 예측 AI를 참고한 경우 다음을 남긴다 — 이 기록이 없으면 **AI 점수만으로 결정했다는 의심을 반박할 수 없다.**

- 사용한 도구·버전, 점수·분류 결과
- 담당자가 종합한 근거(면접·관찰·사건 기록 등)
- 점수와 **다른 결론**을 낸 경우 그 이유
- 취한 조치와 결과

## 4. 기록 시 지켜야 할 3원칙

1. **진술은 원문으로** — 수용자·목격자 진술, 자해·응급 관련 진술은 원문(직접 인용)을 보존한다. AI 요약·윤문은 증거력을 훼손한다.
2. **원문과 산출물을 분리 보관** — AI에 입력한 텍스트와 최종 기록을 따로 남긴다(이의제기·조사 대응).
3. **삭제하지 않는다** — 오류를 발견해 수정한 경우 경위를 남긴다.

## 5. 점검·위반 연결

- 분기 자체점검(`03`) 지표: 표기 누락 0건 / **위험 예측 단독 결정 0건** / 미등록 도구 0건
- 표기 누락 1회 → 보완 지도 / 반복 또는 고영향 기록 → 규정 제20조에 따른 조치
- 연 1회, 사례(익명화)를 교육 자료로 공유한다.

## 6. 현장용 4줄 요약 (교육 자료용)

1. AI 썼으면 **기록 끝에 밝힌다.**
2. **예측 점수는 참고일 뿐, 결정은 내가 한다.** (근거를 남긴다)
3. **진술·응급 상황은 원문 그대로, 요약하지 않는다.**
4. **생체정보·안면인식은 근거 없으면 쓰지 않는다.**
