> 목적: AI 활용을 **기록 단계에서 흔적으로 남긴다.** 표기는 감시가 아니라 ①책임 소재 ②검증 여부 ③평가·기록의 신뢰성 확보 장치다.
> 근거: 「○○○학교 교원 AI 활용 규정」 제11조 — 실행 트리거 ① / 기준일 2026-10-12 / v0.1

## 1. 표기 대상 산출물

| 산출물 | 표기 | 비고 |
|---|---|---|
| 학습자료·수업 프린트 | **필수** | 문항·정답 오류 점검과 함께 |
| 평가문항·정답·해설 | **필수** | 출처·검증 여부 포함 |
| 수행평가 채점 결과지 | **필수** | 채점 기준·배점 근거 첨부 |
| 상담 준비자료·업무 문서 | **필수** | 상담기록 자체는 규정 제10조(입력 금지) |
| 안내문·가정통신문·행사자료 | **필수** | 이미지 생성 포함 |
| 생활기록부·성적 관련 문장 | **표기 필수 + 대체 불가** | 규정 제12조 제1항 — AI 문장 직접 반영 금지 |
| 개인 메모·연습 초안(미제출) | 불요 | 단 학생 정보 입력 금지(규정 제5조) 유지 |
| **부정행위·학교폭력·아동학대 관련 판단 기록** | **표기 불가·AI 사용 금지** | 규정 제5조 3호. 원문 그대로 기록 |

## 2. 표기 형식 (문서 말미 고정란)

```
[AI 활용 표기]
· 활용 여부: □ 사용  □ 미사용
· 도구: (예: 학교 계약 생성형AI A / 문항은행 B) / 버전·접속일
· 활용 범위: 문장 다듬기 / 문항 초안 / 번역 / 요약 / 채점 보조 / 이미지 보정
· 입력 정보: 비식별 가공 후 입력 (학생 개인정보 미입력)
· 검증: 정답·사실·출처 확인 완료 / 미해당
· 최종 작성·판단: 담당 ○○○
```

**양식 개정 권고(우선 조치)**: 평가문항지·학습자료·채점결과지·상담 준비자료 양식 말미에 위 체크란을 **기본 삽입**한다.

## 3. 기록 시 지켜야 할 3원칙

1. **사실은 담당자가 쓴다** — 학생 관찰·평가·생활기록부 문장은 사실에 근거해 담당 교원이 작성한다. AI가 만든 문장을 사실인 것처럼 반영하지 않는다(규정 제12조).
2. **원문과 산출물을 분리 보관** — AI에 입력한 텍스트와 최종 산출물을 따로 남긴다(이의제기·재채점 대응).
3. **삭제하지 않는다** — 오류를 발견해 수정한 경우 수정 경위를 남긴다. 이력이 있어야 재심 절차가 성립한다.

## 4. 판단 근거 기록(재심 대응)

평가·부정행위 판정에서 재심이 요구되면 다음이 **기록으로 남아 있어야** 한다.

- 사용한 AI 도구·버전과 활용 범위
- 채점 기준·배점 근거(수행평가)
- **AI 탐지 결과를 그대로 처분 근거로 삼지 않았다는 사실**과 학생 소명 내용
- 담당 교원의 최종 판단과 그 이유

## 5. 표기 누락·위반 처리

- 학기 자체점검(`03`) 지표: 표기 대상 산출물 중 누락 0건
- 표기 누락 1회 → 보완 지도 / 반복 또는 고영향 산출물 누락 → 규정 제19조에 따른 조치
- **절차 위반으로 학생 불이익이 발생한 경우** → 즉시 원상회복·재채점·재심 개시

## 6. 현장용 4줄 요약 (교원 연수용)

1. AI 썼으면 **자료 끝에 밝힌다.**
2. **학생 이름·상담기록·문항 원본은 절대 붙여넣지 않는다.**
3. **성적·생활기록부 문장은 AI가 쓰게 하지 않는다.** (사실은 내가 쓴다)
4. **AI 탐지 결과만으로 처분하지 않는다.** (소명 기회 먼저)
