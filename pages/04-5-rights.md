> 목적: AI 활용을 **대상자와 보호자가 알 수 있고, 멈출 수 있고, 되돌릴 수 있게** 만든다. 특히 치매·인지저하 대상자의 동의는 **본인 의사 확인 → 후견·법정대리인 동의** 순서를 지킨다.
> 근거: 「○○○요양기관 AI 활용 규정」 제18조 — 실행 트리거 ③, 「개인정보 보호법」(제22조·제23조·제35조~제37조의2), 「노인장기요양보험법」상 계약·급여 절차 / 기준일 2026-10-12 / v0.1

## 1. 적용 대상

| 상황 | 고지 | 동의 | 열람·정정·이의·철회 |
|---|---|---|---|
| 대상자 상시 감시·행동 분석(CCTV AI) (3등급) | 필수 | **필수**(본인 또는 후견인) | 필수 + **철회 시 비영상 대안** |
| 급여·전문서비스 수준 결정 지원 (3등급) | 필수 | **필수** | 필수 |
| 대상자 직접 제공 AI 서비스(돌봄로봇·앱) (3등급) | 필수 | **필수** | 필수 + 종사자 상시 관여 |
| 급여제공기록·케어플랜 작성 보조 (2등급) | 필수(계약 시·연 1회) | 고지로 갈음, 거부 시 사람이 처리 | 필수 |
| 안내문·행사자료 교정 (1등급) | 불요 | 불요 | 해당 없음 |

## 2. 고지 사항 (7개 항목)

1. 어떤 업무에 AI를 쓰는가 (예: "기록 문장을 다듬고, 낙상 위험을 감지합니다")
2. **무엇을 하지 않는가** (예: "AI가 급여를 결정하지 않습니다. 건강 조언을 하지 않습니다")
3. 어떤 정보가 입력되고, 무엇은 입력하지 않는가
4. 감시 기술이 있다면 **설치 위치·범위·화장실 등 제외 공간**
5. AI 활용·감시를 거부할 수 있고 **거부해도 급여·서비스에 불이익이 없다**는 사실
6. 거부 시 대안(사람에 의한 돌봄·비영상 방식)의 내용
7. 문의·정정·이의·철회 창구(담당자 연락처, 법정 기한 10일)

## 3. 계약·초기 상담용 스크립트 (그대로 읽어도 되게)

> "○○님(또는 보호자님), 저희 기관에서는 기록을 정리할 때와 안전사고를 막기 위해 일부 컴퓨터 프로그램(AI)을 씁니다. 성함·건강 정보는 넣지 않고, 급여 내용과 건강 판단은 사람(담당 요양보호사·간호사·사회복지사)이 합니다. AI가 약이나 병원 진료를 지시하는 일은 없습니다. 화장실·목욕실은 촬영·분석하지 않습니다. 원하지 않으시면 해당 기능을 쓰지 않습니다 — 급여나 서비스에는 아무 불이익이 없고, 영상 감지를 원치 않으시면 다른 방식으로 안전을 확인합니다. 나중에 '내 기록에 AI가 쓰였는지' 물어보실 수 있고, 잘못된 부분은 고쳐 달라고 하실 수 있습니다. 담당은 저(○○○)입니다."

## 4. 동의 기록 양식 (3등급 및 직접 제공 서비스)

```
· 대상자: ○○○  · 생년월일: ○○○○-○○-○○  · 요양등급: ○~○등급
· 동의 주체: □ 본인(의사 확인됨)  □ 후견인  □ 법정대리인  □ 그 밖의 정당한 대리 권한자(근거: )
· 본인 의사 확인 방법·결과: (평소 표현·반응 근거 기록 / 확인 불가 사유)
· 설명 내용(체크): □ 활용 범위  □ 미활용 범위  □ 입력 금지 정보  □ 거부권·불이익 없음  □ 대안  □ 문의 창구
· 동의 범위(각각 별도 동의): □ 문서 보조  □ 영상 감지  □ AI 서비스 직접 제공(돌봄로봇·앱)
· 동의 여부: 동의 / 거부 / 부분 동의(범위: )
· 설명자: ○○○ (직위) / 서명 또는 날짜
· 재확인 시점: (예: 6개월 후, 등급 변경 시, 서비스 변경 시)
```
※ **의사능력이 회복되면 본인 의사를 다시 확인**한다(규정 제9조).
※ 대리 권한이 없는 가족(예: 단순 방문 자녀)의 동의로 갈음하지 않는다.

## 5. 열람·정정·이의제기·철회 절차

**접수** — 창구: 담당 요양보호사·사회복지사 / 시설 대표번호 / 서면·구두 가능(구두는 접수자가 기록)

**처리 흐름**
```
접수(당일 기록) → 접수 확인 회신 → 1차 확인(기록 원문·AI 활용 내역 대조)
  → ① 열람 요구: 10일 이내 열람 조치 (개인정보 보호법 제35조·시행령 제41조)
  → ② 정정·삭제 요구: 10일 이내 조치 및 결과 통지 (제36조·시행령 제43조) — 정정 이력 남김
  → ③ 이의제기(AI 결과로 불이익 주장: 급여·서비스 변경 등): 담당자 아닌 제3자(관리담당자 또는 운영위원회)가 검토
      → 접수일부터 10영업일 내 결정·통지, 필요 시 재심의
  → ④ 완전히 자동화된 결정에 대한 거부·설명 요구: 법정 절차로 즉시 안내·처리
      (개인정보 보호법 제37조의2, 시행령 제44조의2, 개인정보위 고시)
  → ⑤ 감시 기술 철회·중단 요청: 즉시 해당 분석 중단 + 비영상 대안 적용, 조치 사실 회신
  → ⑥ 급여기록 정정 요구: 사실 확인 후 정정, 심사·환수 영향 검토

※ ①·②는 법정 기한(10일, 역일), ③은 기관 자체 절차(10영업일)다. 섞어 적용하지 않는다.
```

**기록 필수 항목**: 접수일·요구 내용·검토자·결정·통지일·조치. **기각이어도 기록한다.** 연 1회 접수·처리 건수를 집계해 공개한다.

> **'인적 개입'의 기준(중요)**: 개인정보위 고시는 인적 개입을 **결정을 바꿀 권한이 있는 사람이 실질적으로 관여하는 것**으로 본다. 담당자의 **형식적 확인만으로는 인정되지 않는다.** 검토자가 산출물을 확인하고 근거를 기록하며, 필요 시 **판단을 뒤집을 수 있어야** 한다(규정 제14조의 "근거 기록" 요건과 같은 취지).

## 6. 불이익 금지 조항

- AI 활용·영상 감지 거부, 열람·정정·철회 요구를 이유로 **급여 제한·서비스 축소·계약 해지·차별**이 있어서는 아니 된다.
- 위 사항을 종사자 교육에 포함하고, 위반 시 규정 제19조에 따른다.

## 7. 대상자·보호자에게 제공하는 안내문 1쪽 골격

```
① 우리 기관이 AI를 쓰는 곳 / 쓰지 않는 곳
② 입력하지 않는 정보 (성함·건강·인지기능·가족 정보)
③ 판단은 사람이 한다는 설명 (급여·건강 조언은 AI가 하지 않음)
④ 영상 감지 설치 위치와 제외 공간(화장실·목욕실)
⑤ 거부해도 불이익이 없다는 설명 + 대안 방식
⑥ 문의·정정·이의·철회 창구와 법정 기한(10일)
⑦ 담당자 이름·연락처, 시행일
```
※ 큰 글자 버전과 쉬운 말 버전을 함께 준비한다. 다국어·문해 수준이 낮은 대상자를 고려해 **구두 설명과 서면 안내를 병행**한다.
