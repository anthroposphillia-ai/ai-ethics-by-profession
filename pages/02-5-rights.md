> 목적: AI 활용을 **클라이언트가 알 수 있고, 멈출 수 있고, 되돌릴 수 있게** 만든다. 이 창구가 없으면 기관 규정은 내부 문서에 그친다.
> 근거: 「○○○사회복지관 AI 활용 규정」 제16조 — 실행 트리거 ③, 개인정보 보호법상 정보주체 권리, 사회복지 실천의 자기결정권 원칙 / 기준일 2026-10-12 / v0.2

## 1. 적용 대상

| 상황 | 고지 | 동의 | 열람·정정·이의제기 |
|---|---|---|---|
| AI가 클라이언트 평가·선별·급여 판단에 관여 (3등급) | 필수 | **필수** | 필수 |
| **완전히 자동화된 결정**으로 권리·의무에 중대한 영향 (사람 개입 없음) | 필수 | **필수** | 필수 + **거부권·설명요구권** 안내(개인정보 보호법 제37조의2) |
| AI가 사례기록·계획서 작성에 보조적으로 사용 (2등급) | 필수(안내문·초기 면접 시) | 고지로 갈음, 거부 시 대안 제공 | 필수 |
| 번역·교정·홍보물 등 (1등급) | 불요 | 불요 | 해당 없음 |
| 클라이언트에게 AI 서비스 직접 제공(챗봇 등) | 필수 | **필수** | 필수 + 사람 연계 창구 필수 |

## 2. 고지 사항 (6개 항목을 빠뜨리지 않는다)

1. 어떤 업무에 AI를 쓰는가 (예: "상담 내용을 정리할 때 문장을 다듬는 데 사용합니다")
2. **무엇을 하지 않는가** (예: "AI가 서비스 제공 여부를 결정하지 않습니다. 결정은 담당 사회복지사가 합니다")
3. 어떤 정보가 입력되고, 무엇은 입력하지 않는가
4. AI 활용을 거부할 수 있고, 거부해도 **불이익이 없다**는 사실
5. 거부 시 대안(사람에 의한 처리)의 내용과 소요 시간
6. 문의·이의제기 창구(담당자·연락처·처리 기한)

## 3. 초기 면접용 스크립트 (그대로 읽어도 되게)

> "○○님, 저희 기관에서는 상담 내용을 정리하거나 서류를 작성할 때 컴퓨터 프로그램(AI)의 도움을 받는 경우가 있습니다. 이때 ○○님의 이름이나 상담 내용 원문은 입력하지 않고, 결정도 사람이 합니다. 원하지 않으시면 쓰지 않습니다 — 서비스에는 아무 영향이 없습니다. 나중에 '내 기록에 AI가 쓰였는지' 물어보실 수 있고, 잘못된 부분은 고쳐 달라고 하실 수 있습니다. 담당은 저(○○○)이고, 언제든 말씀해 주세요."

## 4. 동의 기록 양식 (3등급 및 직접 제공 서비스)

```
· 대상자: ○○○  · 일자: ○○○○-○○-○○
· 설명한 내용(체크): □ 활용 범위  □ 미활용 범위  □ 입력 금지 정보  □ 거부권·불이익 없음  □ 대안  □ 문의 창구
· 동의 여부: 동의 / 거부 / 부분 동의(범위: )
· 설명자: ○○○ (직위) / 서명 또는 구두 확인 기록
· 재확인 시점: (예: 6개월 후 또는 서비스 변경 시)
```

## 5. 열람·정정·이의제기 절차

**접수** — 창구: 담당 사회복지사 / 기관 대표번호 / 서면·구두 모두 가능(구두는 접수자가 기록)

**처리 흐름**
```
접수(당일 기록) → 접수 확인 회신 → 1차 확인(기록 원문·AI 활용 내역 대조)
  → ① 열람 요구: **10일 이내 열람** 조치 (개인정보 보호법 제35조·시행령 제41조)
  → ② 정정·삭제 요구: **10일 이내** 조치 및 결과 통지 (제36조·시행령 제43조) — 정정 이력 남김(원문 삭제 아님)
  → ③ 이의제기(AI 결과로 불이익 주장): 담당자 아닌 제3자(관리담당자 또는 윤리위원회)가 검토
      → 접수일부터 10영업일 내 결정·통지, 필요 시 재심의(사람에 의한 재판단)
  → ④ 완전히 자동화된 결정에 대한 거부·설명 요구: 법정 절차로 즉시 안내·처리
      (개인정보 보호법 제37조의2, 시행령 제44조의2, 개인정보위 고시)

※ ①·②는 **법정 기한(10일, 역일)** 이고 ③은 **기관 자체 절차(10영업일)** 다. 두 기한을 섞어 적용하지 않는다.
```

**기록 필수 항목**: 접수일·요구 내용·검토자·결정·통지일·조치. **결과가 '기각'이어도 기록한다.** 연 1회 접수·처리 건수를 집계해 공개한다.

> **'인적 개입'의 기준 (중요)**: 개인정보위 고시는 인적 개입을 **결정을 바꿀 권한이 있는 사람이 실질적으로 관여하는 것**으로 본다. 따라서 담당자의 **형식적 결재만으로는 인적 개입으로 인정되지 않는다.** 검토자가 산출물을 확인하고, 근거를 기록하고, 필요 시 **결정 자체를 뒤집을 수 있어야** 한다(규정 제10조의 "근거 기록" 요건과 같은 취지).

## 6. 불이익 금지 조항

- AI 활용 거부, 열람·정정·이의제기 요구를 이유로 서비스 제공을 제한·중단·차별할 수 없다.
- 위 사항을 종사자 교육에 포함하고, 위반 시 규정 제17조에 따른다.

## 7. 클라이언트에게 제공하는 안내문 1쪽 골격

```
① 우리 기관이 AI를 쓰는 곳 / 쓰지 않는 곳
② ○○님 정보 중 입력하지 않는 것
③ 결정은 사람이 한다는 설명
④ 거부해도 불이익이 없다는 설명
⑤ 문의·정정·이의제기 창구와 처리 기한
⑥ 담당자 이름·연락처, 작성·시행일
```
※ 쉬운 말 버전(큰 글자·그림)과 다국어 버전을 함께 준비하면 접근성이 확보된다.
