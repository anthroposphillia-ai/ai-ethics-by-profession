## B. 위험등급 판정

| 등급 | 판정 기준 (하나라도 해당) | 요구 요건 |
|---|---|---|
| **3 등급(고)** | ①영유아 초상 이미지·영상의 생성·합성·편집 ②발달·행동 선별·추천 ③아동학대·안전사고 기록 관여 ④CCTV·영상 기반 행동 분석 ⑤보호자에게 전달되는 평가 결과 산출 | 운영위원회 심의 + **인간 최종판단 절차 문서화** + 보호자 고지·동의 + 이의제기 창구 + 정기 모니터링 + 결과 공개 |
| **2 등급(중)** | 관찰일지·알림장·상담기록·평가서 작성 보조 / 비식별 정보 처리 / 내부 문서 초안 | 심의 + 사용 표기 의무(`02`) + 교직원 교육 |
| **1 등급(저)** | 안내문·행사자료 문장 교정, 번역, 홍보 문구(영유아 정보 미입력) | 원장 확인 + 사용 표기 |

**원칙**
1. 등급이 불명확하면 **상위 등급으로 판정**한다.
2. **등급 숫자가 클수록 위험하다**(1등급이 가장 낮음). 국내 인증·평가에서 '1등급'이 최고인 경우가 많으니 등급명을 함께 적는다.
3. 범위 관계: **3등급 ⊃ 규정 제2조 제3호 '고영향 활용' ⊃ AI기본법 제2조 제4호 '고영향 인공지능'**. 법상 고영향 AI에 해당하면 반드시 3등급.
4. **영유아 초상이 걸리면 무조건 3등급**이다(예외 없음).

## C. 계약·도입 요건 체크 (심의 통과 조건)

**C-1. 개인정보·데이터**
- [ ] 입력 데이터의 학습 이용 여부 확인 및 학습 미이용 설정(계약 명시)
- [ ] 데이터 보관 기간·삭제 정책, 국외 이전 여부 확인
- [ ] 처리 위탁·국외이전 시 개인정보 보호법상 고지·동의·안전조치 요건 충족
- [ ] 암호화·접근통제·로그 보존 조항 계약 반영
- [ ] 사고 발생 시 통지 의무·기한 명시
- [ ] **영유아 이미지 업로드 차단 설정** 확인(서비스가 업로드 자체를 학습에 쓰는지)

**C-2. 성능·검증**
- [ ] 시험 운영(파일럿) 및 결과 기록
- [ ] 오류·환각(hallucination) 대응 절차 문서화
- [ ] 낙인·차별 표현 생성 사례 점검(해당 등급)
- [ ] 버전 변경·모델 교체 시 재심의 조건 명시 ← *비정적 대상이므로 필수*
- [ ] 고영향·생성형 AI 서비스 제공 시 **이용자 사전 고지 문구** 준비(AI기본법 제31조 제1항)
- [ ] 영향평가는 법상 **'노력의무'**(제35조) — 기관은 내규로 의무화한 것이므로 이행 기록을 남긴다
- [ ] 완전히 자동화된 결정이 있는 경우 **거부·설명 요구 절차**(개인정보 보호법 제37조의2) 안내 창구 마련

**C-3. 조직·책임**
- [ ] 담당자·개인정보보호책임자 지정
- [ ] 교직원 교육 계획(도입 전 1회)
- [ ] 표기 방법이 기존 양식에 반영됨
- [ ] 위반·사고 보고 경로 명시

**C-4. 보호자 권리 (3등급 및 보호자 접촉 서비스)**
- [ ] 보호자 고지문·동의 절차 준비(`04`)
- [ ] **법정대리인 확인 방법**(친권자 여부, 필요 시 가족관계 확인)
- [ ] 열람·정정·이의제기 접수 창구 및 법정 기한(10일)
- [ ] 사람에 의한 처리로 전환 가능한 절차

## D. 운영 중 점검 (분기 1회)

- [ ] 표기 누락 0건인가 (`02`)
- [ ] 위반·사고·보호자 요구 접수 및 조치 기록(없어도 "0건"으로 기록)
- [ ] 등록된 도구 목록과 실제 사용 도구가 일치하는가(**미등록 도구 사용 여부**)
- [ ] 서비스 약관·모델 버전 변경 여부(있으면 재심의)
- [ ] 교육 이수율
- [ ] 보호자 안내문 게시 상태
- [ ] **영유아 사진·영상 게시물에 대한 철회 요구 처리 건수**

## F. 불승인 기준

1. 영유아 이미지를 학습에 이용하며 해제가 불가능한 서비스
2. 발달·행동 선별·진단을 자동 산출하는 서비스
3. 아동학대·안전사고 관련 기록에 AI 요약·윤문이 개입하는 구성
4. 오류·이의제기 창구가 없고 제공자가 대응 의무를 지지 않는 서비스
5. 3등급인데 인간 최종판단 절차를 문서화할 수 없는 경우
6. 사고 통지·삭제 요구에 대한 계약상 근거가 없는 경우
