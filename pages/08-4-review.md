## L. 법적 근거 확인 (교정·소방 특유 — 필수 관문)

- [ ] 권리 제한적 활용에 **법률·훈령상 근거**가 있는가 (없으면 불승인)
- [ ] 생체정보·안면인식 사용의 근거 법령 확인(개인정보 보호법 제23조·생체정보 관련 규정)
- [ ] 수용자 처우 관련 법령(형의 집행 및 수용자의 처우에 관한 법률·시행령)상 허용 범위 확인
- [ ] 재난·구조 활동 관련 법령(소방기본법 등)상 지휘·판단 권한 구조와 충돌하지 않는가
- [ ] 상급기관·국가인권위 권고·판례 동향 확인(유사 사례에서 위법·부적정 판단 여부)

## B. 위험등급 판정

| 등급 | 판정 기준 (하나라도 해당) | 요구 요건 |
|---|---|---|
| **3 등급(고)** | ①위험 예측 ②생체정보·안면인식 ③상시 감시·행동분석 ④처우·징계·신분 결정 지원 ⑤응급·구조 판단 지원 | 위원회 심의 + **법적 근거 확인** + 인간 최종판단 문서화 + 대상자 고지·이의 창구 + 정기 모니터링 + 결과 공개 |
| **2 등급(중)** | 문서 요약·작성 보조, 통계·분석(비식별), 내부 보고 초안 | 심의 + 사용 표기 의무(`02`) + 직원 교육 |
| **1 등급(저)** | 안내문 문장 교정, 번역(개인정보 미입력) | 기관장 확인 + 사용 표기 |

**원칙**
1. 등급이 불명확하면 **상위 등급으로 판정**한다.
2. **등급 숫자가 클수록 위험하다**(1등급이 가장 낮음).
3. 범위 관계: **3등급 ⊃ 규정 제2조 제3호 '고영향 활용' ⊃ AI기본법 제2조 제4호 '고영향 인공지능'** — 법상 고영향에는 **생체인식**이 명시된다.
4. **생체정보·위험 예측이 걸리면 무조건 3등급 + 법적 근거 확인**이다.
5. 응급·구조 판단을 **AI로 자동화**하는 구성은 불승인한다.

## C. 계약·도입 요건 체크

**C-1. 개인정보·데이터**
- [ ] 학습 이용 여부 확인 및 미이용 설정(계약 명시)
- [ ] 보관 기간·삭제 정책, 국외 이전 여부 확인
- [ ] 처리 위탁·국외이전 시 개인정보 보호법상 요건 충족
- [ ] 생체정보 별도 보관·암호화·삭제 기준 명시
- [ ] 사고 발생 시 통지 의무·기한 명시

**C-2. 성능·검증**
- [ ] 파일럿 및 결과 기록 — **오탐·미탐률 필수**(위험 예측·감시)
- [ ] 예측 모델의 입력 변수·정확도·편향 점검 자료 확보
- [ ] 오류·환각 대응 절차 문서화
- [ ] 버전 변경·모델 교체 시 재심의 조건 명시
- [ ] 사전 고지 문구 준비(AI기본법 제31조 제1항)
- [ ] 영향평가(법 제35조, **노력의무**) 이행 기록 체계
- [ ] 완전히 자동화된 결정이 있는 경우 거부·설명 요구 절차(개인정보 보호법 제37조의2) 창구

**C-3. 인권·현장 안전**
- [ ] 감시 범위에서 **사생활 공간 제외** 확인
- [ ] 분석 결과를 **직원 성과평가·부당 처우에 쓰지 않음**을 계약·내규로 명시
- [ ] 응급·구조 상황에서 **AI를 우회할 수 있는 절차**(중단·수동 모드) 마련
- [ ] 출동·자원 배분 AI의 **최종 결정권이 지휘관**에게 있음을 문서화
- [ ] 대상자 고지문·이의 창구 준비(`04`)

**C-4. 조직·책임**
- [ ] 담당자·개인정보보호책임자 지정
- [ ] 직원 교육 계획(도입 전 1회, 인권 기준 포함)
- [ ] 상급기관 보고·승인 요건 확인
- [ ] 위반·사고 보고 경로 명시

## D. 운영 중 점검 (분기 1회)

- [ ] 표기 누락 0건 / **위험 예측 단독 결정 0건** (`02`)
- [ ] 감시·예측 사용 범위가 승인 범위 내인가
- [ ] 오탐·미탐 사례와 조치 기록
- [ ] 대상자 이의·열람 요구 접수 및 처리 기록
- [ ] 등록 도구 목록과 실제 사용 도구 일치
- [ ] 약관·모델 버전 변경 여부(있으면 재심의)
- [ ] 교육 이수율, 응급 우회 절차 훈련 실시 여부

## F. 불승인 기준

1. 권리 제한적 활용인데 **법적 근거가 없는** 경우
2. 위험 예측을 **단독 처분 근거로 삼도록** 설계된 구성
3. 생체정보·안면인식을 **동의·법령 근거 없이** 수집·보관하는 구성
4. 응급·구조 판단을 **AI가 자동 확정**하는 구성
5. 감시 결과를 직원 평가·부당 처우에 사용하는 것을 계약상 허용하는 시스템
6. 오류·이의제기 창구가 없고 제공자가 대응 의무를 지지 않는 서비스
