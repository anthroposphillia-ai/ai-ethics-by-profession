> 목적: AI 활용을 **내담자가 알 수 있고, 멈출 수 있고, 되돌릴 수 있게** 만든다. 단 **위기 상황에서는 고지·동의 절차가 생명 보호를 지연시켜서는 안 된다.**
> 근거: 「○○○상담기관 AI 활용 규정」 제17조·제19조·제9조 — 실행 트리거 ③, 「개인정보 보호법」(제22조·제23조·제35조~제37조의2), 자살예방법상 조치 / 기준일 2026-10-12 / v0.1

## 2. 고지 사항 (7개 항목)

1. 어떤 업무에 AI를 쓰는가 (예: "상담기록 문장을 정리하는 데 사용합니다")
2. **무엇을 하지 않는가** (예: "진단과 해석은 상담자가 합니다. 위기 상황은 AI가 판단하지 않습니다")
3. 어떤 정보가 입력되고, 무엇은 입력하지 않는가(축어록·녹음·검사 원자료 미입력)
4. AI 활용을 거부할 수 있고 **거부해도 상담에 불이익이 없다**는 사실
5. 거부 시 대안(사람에 의한 처리)의 내용
6. 열람·정정·이의제기 창구와 법정 기한(10일)
7. **챗봇·앱을 사용하는 경우**: 사람 상담을 대신하지 않는다는 한계, 위기 시 연계 방법, 긴급 연락처

## 3. 상담계약(초기 면접)용 스크립트 (그대로 읽어도 되게)

> "○○님, 저희 기관에서는 상담기록을 정리할 때 컴퓨터 프로그램(AI)의 도움을 받는 경우가 있습니다. 이름·상담 내용 원문·녹음 파일은 넣지 않고, 진단과 해석은 담당 상담자가 합니다. 원하지 않으시면 쓰지 않습니다 — 상담에는 아무 영향이 없습니다. 위험한 이야기가 나올 때는 AI가 아니라 사람이 판단합니다. 나중에 기록에 대해 물어보실 수 있고, 잘못된 부분은 고쳐 달라고 하실 수 있습니다. 담당은 저(○○○)입니다."

**14세 미만 아동·청소년**: 법정대리인에게 설명하고 동의를 받되, **본인에게도 같은 내용을 나이에 맞게 설명**하고 본인 의사를 확인한다.

## 4. 동의 기록 양식

```
· 내담자: ○○○  · 생년월일: ○○○○-○○-○○  · 14세 미만 여부: 예/아니오 (예: 법정대리인 동의 필수)
· 동의 주체: □ 내담자 본인  □ 법정대리인(관계: )
· 설명 내용(체크): □ 활용 범위  □ 미활용 범위  □ 입력 금지 정보  □ 거부권·불이익 없음  □ 대안  □ 창구  □ 위기 시 사람 판단
· 동의 범위(각각 별도 동의): □ 기록 보조  □ 슈퍼비전 활용  □ 챗봇·앱 사용  □ 녹음·전사
· 동의 여부: 동의 / 거부 / 부분 동의(범위: )
· 설명자: ○○○ (직위) / 서명 또는 날짜
· 재확인 시점: (예: 6개월 후, 서비스 변경 시)
```
※ **기록 보조 동의와 챗봇 사용 동의는 별개**다. 하나로 묶지 않는다.

## 5. 열람·정정·이의제기·철회 절차

**접수** — 창구: 담당 상담자 / 기관 대표번호 / 서면·구두(구두는 접수자가 기록)

**처리 흐름**
```
접수(당일 기록) → 접수 확인 회신 → 1차 확인(기록 원문·AI 활용 내역 대조)
  → ① 열람 요구: 10일 이내 열람 조치 (개인정보 보호법 제35조·시행령 제41조)
  → ② 정정·삭제 요구: 10일 이내 조치 및 결과 통지 (제36조·시행령 제43조) — 정정 이력 남김
  → ③ 이의제기(AI 활용·서비스로 불이익 주장): 담당자 아닌 제3자(관리담당자 또는 윤리위원회)가 검토
      → 접수일부터 10영업일 내 결정·통지, 필요 시 재심
  → ④ 완전히 자동화된 결정에 대한 거부·설명 요구: 법정 절차로 즉시 안내·처리
      (개인정보 보호법 제37조의2, 시행령 제44조의2)
  → ⑤ 챗봇·앱 사용 중단 요청: 즉시 중단 + 사람 상담 전환
  → ⑥ 기록 열람 시 제3자(보호자·가족) 개인정보 보호 범위 조정

※ ①·②는 법정 기한(10일, 역일), ③은 기관 자체 절차(10영업일)다. 섞어 적용하지 않는다.
```

**기록 필수 항목**: 접수일·요구 내용·검토자·결정·통지일·조치. **기각이어도 기록한다.** 분기별 접수·처리 건수를 집계해 공개한다.

> **'인적 개입'의 기준(중요)**: 개인정보위 고시는 인적 개입을 **결정을 바꿀 권한이 있는 사람이 실질적으로 관여하는 것**으로 본다. 담당자의 형식적 확인만으로는 인정되지 않는다 — 검토자가 산출물을 확인하고 근거를 기록하며 필요 시 **판단을 뒤집을 수 있어야** 한다.

## 6. 위기에 관한 예외 (이 지침에서 가장 중요)

1. **동의 절차가 긴급 조치를 지연시켜서는 안 된다.** 자살·자해·학대 등 위기 상황에서는 고지·동의 절차 이행을 이유로 응급 조치·신고를 미룰 수 없다.
2. 위기 관련 정보는 **AI 활용 대상에서 제외**한다(요약·윤문·번역 금지, 규정 제9조).
3. 위기 상황에서 내담자가 AI 챗봇만 사용하던 경우라도, 사람 상담자·응급기관 연계는 **동의와 무관하게** 진행한다(법령상 조치).
4. 보호자 통보가 필요한 경우(미성년 자해 등) 기관 규정과 법령에 따르며, **통보 여부·방식이 내담자 안전을 해치지 않는지** 담당자와 슈퍼바이저가 판단한다.

## 7. 불이익 금지 조항

- AI 활용 거부, 열람·정정·이의·중단 요구를 이유로 **상담 중단·회기 축소·차별**이 있어서는 아니 된다.
- 위 사항을 종사자 교육에 포함하고, 위반 시 규정 제20조에 따른다.

## 8. 내담자 안내문 1쪽 골격

```
① 우리 기관이 AI를 쓰는 곳 / 쓰지 않는 곳
② 입력하지 않는 정보 (이름·상담 원문·녹음·검사 원자료)
③ 진단·해석은 상담자가 한다는 설명
④ 위기 상황에서는 AI가 아니라 사람이 판단한다는 설명 + 긴급 연락처
⑤ 챗봇 사용 시 한계와 사람 연계 방법
⑥ 거부해도 불이익이 없다는 설명
⑦ 문의·열람·정정·이의 창구와 법정 기한(10일), 시행일
```
