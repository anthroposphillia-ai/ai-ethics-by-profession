## B. 위험등급 판정

| 등급 | 판정 기준 (하나라도 해당) | 요구 요건 |
|---|---|---|
| **3 등급(고)** | 서비스 제공 여부·수준·급여·자격·퇴소 등 신분에 영향 / 취약계층 선별·표적화 / 민감정보 처리 | 위원회 심의 + **인간 최종판단 절차 문서화** + 클라이언트 고지·이의제기 창구 + 정기 모니터링 + 결과 공개 |
| **2 등급(중)** | 사례기록·평가서 등 업무 문서 작성 보조 / 비식별 정보 처리 / 내부 의사결정 참고 | 심의 + 사용 표기 의무(`02`) + 담당자 교육 |
| **1 등급(저)** | 번역·문장 교정·홍보물 제작 등 클라이언트 영향 없음, 개인정보 미입력 | 부서장 확인 + 사용 표기 |

**원칙**
1. 등급이 불명확하면 **상위 등급으로 판정**한다.
2. **등급 숫자가 클수록 위험하다**(1등급이 가장 낮음). 국내 인증·평가에서 '1등급'이 최고 등급인 경우가 많아 혼동하므로 표에 등급명을 함께 적는다.
3. 범위 관계: **3등급 ⊃ 규정 제2조 제3호 '고영향 활용' ⊃ AI기본법 제2조 제4호 '고영향 인공지능'**. 즉 3등급에 해당해도 법상 고영향 AI가 아닐 수 있고, 법상 고영향 AI에 해당하면 반드시 3등급으로 판정한다.

## C. 계약·도입 요건 체크 (심의 통과 조건)

**C-1. 개인정보·데이터**
- [ ] 입력 데이터의 학습 이용 여부 확인 및 학습 미이용 설정(또는 계약 명시)
- [ ] 데이터 보관 기간·삭제 정책 확인, 국외 이전 여부 확인
- [ ] 처리 위탁·국외이전 시 개인정보 보호법상 고지·동의·안전조치 요건 충족
- [ ] 암호화·접근통제·로그 보존 조항 계약 반영
- [ ] 사고 발생 시 통지 의무·기한 계약 명시

**C-2. 성능·검증**
- [ ] 도입 전 시험 운영(파일럿) 및 결과 기록
- [ ] 오류·환각(hallucination) 대응 절차(검증 단계) 문서화
- [ ] 편향·차별 가능성 점검 방법 확인(해당 등급)
- [ ] 버전 변경·모델 교체 시 재심의 조건 명시 ← *비정적 대상이므로 필수 조항*
- [ ] 고영향·생성형 AI 서비스 제공 시 **이용자 사전 고지 문구** 준비(AI기본법 제31조 제1항)
- [ ] 영향평가는 법상 **'노력의무'**(제35조)임을 확인 — 기관은 내규로 의무화한 것이므로 이행 기록을 남긴다
- [ ] 완전히 자동화된 결정이 있는 경우 **거부·설명 요구 절차**(개인정보 보호법 제37조의2) 안내 창구 마련

**C-3. 조직·책임**
- [ ] 담당자·개인정보보호책임자 지정
- [ ] 종사자 교육 계획(도입 전 1회)
- [ ] 사용 표기 방법이 기존 문서 양식에 반영됨
- [ ] 위반·사고 보고 경로 명시

**C-4. 권리 보장 (3등급 및 클라이언트 접촉 서비스)**
- [ ] 클라이언트 고지문·동의 절차 준비(`04`)
- [ ] 열람·정정·이의제기 접수 창구 및 처리 기한
- [ ] 사람에 의한 서비스로 전환 가능한 절차

## D. 운영 중 점검 (분기 1회)

- [ ] 사용 표기 누락 0건인가 (`02`)
- [ ] 위반·사고·이의제기 접수 및 조치 기록이 있는가 (없어도 "0건"으로 기록)
- [ ] 등록된 AI 도구 목록과 실제 사용 도구가 일치하는가 (**미등록 도구 사용 여부**)
- [ ] 서비스 약관·모델 버전 변경이 있었는가 (있으면 재심의)
- [ ] 교육 이수율
- [ ] 클라이언트 안내문 배포·게시 상태

## F. 불승인 기준 (예시 — 기관이 조정)

1. 클라이언트 식별정보를 학습에 이용하며 해제가 불가능한 서비스
2. 고영향 결정을 AI 단독으로 내리도록 설계된 서비스
3. 오류·이의제기 창구가 없고 제공자가 대응 의무를 지지 않는 서비스
4. 위험등급 3등급인데 인간 최종판단 절차를 문서화할 수 없는 경우
5. 사고 통지·삭제 요구에 대한 계약상 근거가 없는 경우
