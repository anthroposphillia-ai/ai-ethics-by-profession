> 목적: AI 활용을 **기록 단계에서 흔적으로 남긴다.** 급여제공기록은 심사·환수의 근거이므로, 표기는 ①책임 소재 ②실제 제공과의 일치 ③사후 확인 가능성을 확보하는 장치다.
> 근거: 「○○○요양기관 AI 활용 규정」 제12조·제13조 — 실행 트리거 ① / 기준일 2026-10-12 / v0.1

## 2. 표기 형식 (문서 말미 고정란)

```
[AI 활용 표기]
· 활용 여부: □ 사용  □ 미사용
· 도구: (예: 기관 계약 생성형AI A) / 버전·접속일
· 활용 범위: 문장 다듬기 / 초안 생성 / 번역 / 요약
· 입력 정보: 비식별 가공 후 입력 (대상자 개인정보 미입력)
· 급여 사실 확인: 실제 제공한 급여·시간과 일치함을 담당자 확인
· 최종 작성·판단: 담당 ○○○
```

**양식 개정 권고(우선 조치)**: 급여제공기록·업무일지·케어플랜 양식 말미에 위 체크란을 **기본 삽입**한다. 누락의 주원인은 태만이 아니라 **양식에 칸이 없는 것**이다.

## 3. 기록 시 지켜야 할 4원칙

1. **제공 사실은 사람이 쓴다** — 시간·범위·제공 내용은 담당자가 실제에 근거해 기재한다. AI가 만든 문장으로 사실을 대체할 수 없다(규정 제13조).
2. **원문과 산출물을 분리 보관** — AI에 입력한 텍스트와 최종 문서를 따로 남긴다(심사·정정 요구 대응).
3. **삭제하지 않는다** — 잘못 반영했다가 발견한 경우 수정 경위를 남긴다. 덮어쓰기는 심사 대응력을 잃게 만든다.
4. **사실과 추정을 구분한다** — `대상자가 ~하셨다`(관찰)와 `~인 것 같다`(추정)를 섞지 않는다. AI는 추정을 사실처럼 서술하는 경향이 있다.

## 4. 슈퍼비전·사례회의에서 확인할 사항

- 이 기록에서 AI가 만든 문장은 어느 부분인가? 실제 제공 내용과 일치하는가?
- **제공하지 않은 급여·과장된 시간이 들어가지 않았는가?**(환수 리스크)
- 대상자의 말·행동을 AI가 추정해 서술한 부분이 있는가?
- 낙인·평가적 표현("문제 대상자", "퇴소 대상")이 들어오지 않았는가?
- 보호자·심사기관에 제출되는 문서인가? 그렇다면 사실 확인을 거쳤는가?

## 5. 점검·위반 연결

- 분기 자체점검(`03`) 시 **표기 누락률**을 지표로 삼는다(권장: 누락 0건).
- 위반 처리: 표기 누락 1회 → 보완 지도 / **급여기록 부정 기재 → 규정 제19조 제3호 절차(시정·환수·신고 검토)**
- 연 1회, 우수·위험 사례를 익명화해 종사자 교육 자료로 공유한다.

## 6. 현장용 4줄 요약 (교육 자료용)

1. AI 썼으면 **기록 끝에 밝힌다.**
2. **이름·건강·인지기능 정보는 절대 붙여넣지 않는다.**
3. **제공한 것만 쓴다.** (AI가 문장을 만들어도 사실은 내가 쓴다)
4. **건강 조언은 AI에게 묻지 않는다.** (이상이 보이면 간호사에게 보고)
